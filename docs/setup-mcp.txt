1 - instalar o kicad via snap. Versão 9 ou superior.

2- clonar o respositório do mcp no github:
```
mkdir -p ~/mcp
cd ~/mcp
git clone https://github.com/mixelpixx/KiCAD-MCP-Server.git
```

3 -  instalar as dependências do projeto e compilar o projeto:

```
npm install 
npm run build
```

4 - Verificar se o servidor está funcionando corretamente:
```
ls -lh ~/mcp/KiCAD-MCP-Server/dist/index.js
```

5 - Habilitar a api do kicad

Em um novo projeto, vá em : Preferences → Plugins → Enable IPC API Server

ver imagem em docs/imagens/habilitar-complemento-kicad9.png

      "args": [],
      "env": {
        "NODE_ENV": "production",
        "LOG_LEVEL": "info",
        "KICAD_AUTO_LAUNCH": "false",
        "KICAD_MCP_DEV": "0",
        "KICAD_BACKEND": "auto",

´´´

OSB.: devido a instalação via snap, o caminho do kicad é diferente do padrão. Ajuste o caminho do kicad no arquivo mcp.json de acordo com a sua instalação.

7 - No vscode Crtl + Shift + P → MCP: Start Server

Inicalize o servidor e verifique se o mesmo está funcionando corretamente.

8 - No vscode Crtl + Shift + P → MCP: Open MCP Panel
